## 1. 一句话任务

把现有 HoloOcean 仿真环境改成**我们即将到货那台 ROV 的数字孪生**，并让仿真器**按真机设备的线上格式输出数据**，使真机到货前，所有 adapter、SLAM 算法、飞控接口和飞手训练都能在仿真上先跑起来。

你的产出决定后面所有算法和 adapter 工作有没有测试台。你不是在做"仿真 demo"，是在做这两个月全团队的验证基础设施。

## 2. 五分钟背景

**硬件**（合同已签，细节在 `docs/ROV平台参数.md`）：BlueROV2 Heavy，ArduSub 飞控，供应商不给 SDK 也不做算法；**单目** IMX462 云台相机（后续会另装双目，型号未定）；外挂维特 HWT9053-485 IMU 经树莓派 USB；**无 DVL，后期也不装**；前视声呐 768 波束、140°×20°、40 Hz，只出灰度图；tether 实测 10–40 Mbps。

**这意味着**：仓库现有的双目 VO 主线在到货形态下用不了，第一阶段定位靠 IMU 预积分 + 声呐帧间配准 + 深度 + 磁航向（规格 D-1）。这些算法全部要在你搭的仿真上开发和验证。

**仿真现状**（你接手时的起点）：
- HoloOcean 2.3.0 装在 Windows 那台机器上（WSL2 里跑不起来，别再试，已经证明是死路）。
- Windows 侧 `holoocean_bridge_sensor_host.py` 持有 HoloOcean，经自定义 TCP 协议把原始帧送到 WSL2 侧 `bridged_realtime_ros_session.py`，再转成 ROS2 话题，C++ 网关 `holoocean_realtime_node` 接进管线。这条链 2026-08-27 实跑过 14 分钟，0 丢帧。
- 场景基线 `adapters/holoocean/scenarios/blue_rov_aid_sv1213_base.json`：机体已是 `BlueROV2`，世界 `PierHarbor`，但传感器是双目 20 Hz + IMU 50 Hz + 声呐 10 Hz，跟合同机器差得远。
- 实测 tick 率只有每秒 12–13 个，配置写的是 100。这是你第一周就要量清楚的事。
- 这条桥接链的运行方法**只写在三个模块的 docstring 里**（`raw_frame_wire.py`、`holoocean_bridge_sensor_host.py`、`bridged_realtime_ros_session.py`），`adapters/holoocean/README.md` 第 9 行起那段"本机没有 HoloOcean"已经过时。你上手后第一件文档工作就是把运行步骤补进 README。

## 5. 硬性规则（违反任何一条都要返工）

1. **不改 `external_repos/` 下任何东西**，包括 `holoocean-ros`。
2. **依赖只能单向**：你的代码全部在 `adapters/holoocean/` 和 `adapters/ros2/`，`include/`、`src/` 下的核心层不许 include HoloOcean、ROS、OpenCV。改完跑 `tools/lint/check_no_ros_in_core.sh`。
3. **真值隔离**：`/uw/sim/ground_truth` 只能进评分器，任何算法输入 topic 和伪装流都不许带真值。`scenario_manifest.py` 有校验，新加配置必须过它。
4. **不用欧拉角**，位姿一律 `Pose3`（平移 + 四元数 xyzw）。
5. **随机数用显式 seed 的 RNG 传到调用点**，不许全局 seed，不许中途重 seed。
6. **不 `git commit`**，除非技术负责人明确说提交。工作树里别人的改动不许动。
7. **消息模型改 `.proto`**，不在 Python 侧另建平行 struct。
8. **不删双目通路**，一切单目改造做成可配。
9. 改完代码的验证顺序：编译 → C++ 测试 → `(cd adapters/holoocean && .venv/bin/pytest -q)` → lint → **实跑一次端到端**。仓库里有两个 bug 是单测全绿、实跑才发现的，别只信单测。

## 9. 环境与已知的坑

- **Windows 那台机器**：HoloOcean 安装、验证脚本在 `C:\Users\pengb\uw_slam_holoocean_check\`。从 WSL2 调 Windows 侧要走 `powershell.exe`，必须用 `.py` 文件不能用 `-c` 内联，且 `-WorkingDirectory` 要给真实本地路径，否则报 WinError 4551。
- **WSL2 侧**：本机有三个 Python（conda base、`~/.local/bin` 下 uv 装的、系统 `/usr/bin/python3`）。`colcon build` 要系统 Python 在前（`PATH="/usr/bin:/opt/ros/jazzy/bin:/bin"`），`cmake -DUW_BUILD_ROS2=ON` 要 conda 的 cmake 4.x 在前。两步 PATH 顺序相反，不能一套环境变量走到底。
- **apt/rosdep 卡住**先查代理：`/etc/apt/apt.conf.d/95proxy` 和 `sudo -E`。
- **WSL2↔Windows 的 TCP 长连接会掉**，桥接里已有重连循环，别当 bug 修。
- **HoloOcean 慢于实时**是常态，所有时间戳用仿真时间，延迟指标按仿真时间算。
- **HoloOcean 声呐没有波束宽度参数**，两种频率模式的角向分辨率差异仿不出来，只能调噪声近似，记进规格条目就行。
- `adapters/holoocean/README.md` 第 9 行起"本机没有 HoloOcean"那段已过时，别被误导。
